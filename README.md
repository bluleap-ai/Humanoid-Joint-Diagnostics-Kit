# Humanoid Joint Diagnostics Kit

Wireless CAN/CAN FD diagnostics using **XIAO ESP32-C5 + Adafruit CAN Pal**, Zephyr firmware, and a Python CLI/TUI.

- Local Wi-Fi with mutual TLS, live capture, DBC decoding, recording, and finite transmission.
- Firmware builds; 126 automated tests pass. **Hardware validation is pending.**
